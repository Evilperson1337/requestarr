# UI Mockups

## Final decision references

- `01-game-request-modal-dynamic-platforms.png` — universal request modal; game variant with Any first plus dynamic multi-select supported platforms.
- `02-requests-shared-mixed-artwork.png` — shared Requests page; no private My Requests navigation; square music art coexists with poster art.
- `03-home.png` — link-first Home with recent requests/recently available/admin review summary.
- `04-settings-libraries.png` — settings information architecture and library health/sync cards.
- `05-setup-wizard.png` — left-progress first-run wizard; shown on Metadata Providers step.

The mockups are visual direction, not exact pixel specs. Some generated labels/examples may conflict with later written decisions; **written decisions in `docs/DECISIONS.md` and `docs/UI_UX.md` win**. For example, the final product name is currently Requestarr even where a mockup says “Request Hub.”

Earlier exploratory iterations are intentionally excluded from repository history. Only the authoritative decision references under `final/` are retained.
