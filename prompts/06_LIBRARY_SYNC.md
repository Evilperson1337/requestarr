# Prompt 06 — Availability Sources

Implement library source configuration and background inventory sync for Plex, Jellyfin, Navidrome/OpenSubsonic, and RomM. Each source can be authoritative only for configured media types. Persist normalized inventory and cursors. Use pagination/deltas where APIs support them. A failed/unreachable source must retain its last-known inventory and must never emit mass removals. Expose health, item counts, last successful sync, next sync, Test Connection, and Sync Now. Add fixtures and outage tests. The planned Audiobookshelf adapter is separately gated by Prompt 11; never use metadata or Chaptarr as audiobook availability authority.
