# Contributing

Requestarr is a working prototype and is not yet V1-complete (see `docs/IMPLEMENTATION_PLAN.md`). Before contributing, read `AGENTS.md`, `docs/V1_SCOPE.md`, and `docs/DECISIONS.md`.

Use focused changes, add tests for behavior, never commit secrets or fetched reference checkouts, and do not add acquisition/downloader scope without an explicit product decision. Run `scripts/check.sh` before opening a pull request.
