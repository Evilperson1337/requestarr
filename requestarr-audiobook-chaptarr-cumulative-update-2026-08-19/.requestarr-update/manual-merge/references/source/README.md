# Reference source

These repositories are optional local research checkouts and are not Requestarr dependencies. Run `scripts/fetch-references.sh` or `.ps1` on a networked development machine. `references/source/checkouts/` should remain uncommitted.

Consult `manifest.yaml` for the purpose of each reference. Do not copy source across license boundaries without explicitly reviewing the upstream license and Requestarr's eventual project license.

Chaptarr is included specifically as an audiobook/book domain and matching reference. Do not treat its downloader/indexer/acquisition architecture as Requestarr scope.
