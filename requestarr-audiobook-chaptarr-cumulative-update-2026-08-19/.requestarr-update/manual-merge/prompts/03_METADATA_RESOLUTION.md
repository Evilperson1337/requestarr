# Prompt 03 — Metadata URL Resolution

Implement the resolver registry and provider adapters for TMDB movie/TV URLs, MusicBrainz release-group/recording URLs, IGDB game URLs, and Audible audiobook product URLs resolved/enriched through Audnexus. Resolver output must be provider-neutral `domain.ResolvedItem`. Add bounded HTTP clients, caching, rate-limit awareness, error taxonomy, sanitized fixtures, and tests for malformed/unsupported URLs. IGDB must return the game's actual supported platforms for dynamic request controls. Audiobook resolution must preserve ASIN, storefront region, authors, narrators, series/position, runtime, and source-native cover metadata when available; cache normalized output so existing request pages do not require live Audnexus. Do not add global search/discovery.
