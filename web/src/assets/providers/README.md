# Integration logos

Shown next to each integration in Settings so an operator can recognise it. They are the property of their owners and appear only to identify the service Requestarr connects to.

| File | Source |
| --- | --- |
| plex.svg, jellyfin.svg, themoviedatabase.svg, musicbrainz.svg, igdb.svg | simple-icons 14.15.0 (CC0), coloured with each brand's published colour |
| navidrome.png | github.com/navidrome/navidrome, `resources/logo-192x192.png` (GPL-3.0) |
| romm.svg | github.com/rommapp/romm, `frontend/assets/isotipo.svg` (GPL-3.0) |
| apprise.svg | drawn for Requestarr (a generic bell); Apprise publishes no standalone mark |

The official TMDB attribution logo (`../tmdb-attribution.svg`, "Primary long") is downloaded from themoviedb.org/about/logos-attribution and shown in the app footer as its API terms require; it is not the simple-icons mark above.
